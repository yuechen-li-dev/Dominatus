# Dominatus robotics deferred work

M7's quadcopter samples are deterministic simulation experiments, not production or certified flight software. They establish neither formal stability nor a replacement for control theory. The conventional controller was shorter and faster in the bounded fixture; Dominatus concentrated persistent state, recovery, typed obligations, inspection, and bounded LLM escalation above the fast loop.

Robotics work is paused after M8. The next active integration target is Skyrim MarionetteSSE.

| Deferred item | Why it matters | Resume only with evidence |
| --- | --- | --- |
| Quaternion/SO(3), translation, estimator sophistication, stability analysis | Needed for serious flight-control claims | A separately approved control-research objective and mathematical validation plan |
| Randomized campaigns, actuator asymmetry, payload shifts, allocation redesign | Useful experiment depth | A measured decision that the existing fixture no longer answers the architecture question |
| Linux OpenCV packaging, SIL/PX4/ROS, HIL, physical flight, hard real-time | Required for deployment, not kernel proof | An owned deployment program, hardware safety plan, and real-time acceptance criteria |
| Change-amplification experiments | Could refine the comparison | A new bounded study with an independent decision value |
